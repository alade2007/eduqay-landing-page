# EduQay Landing Page

A modern, responsive landing page for **EduQay**, a school result and academic management platform built for Nigerian schools.

 📌 About the Project

EduQay helps schools simplify academic result processing by allowing teachers and administrators to manage scores, calculate results, generate report cards, and handle academic records more efficiently.

This project focuses on creating a clean, professional, and user-friendly landing page that introduces EduQay, communicates its key benefits, and encourages schools to get started.

🎯 Project Goals

* Present EduQay's value clearly to schools and administrators.
* Create a modern and professional SaaS-style interface.
* Provide a responsive experience across desktop, tablet, and mobile devices.
* Showcase EduQay's key features and workflow.
* Make it easy for visitors to register their school or learn more about the platform.

✨ Features

* Responsive navigation bar
* Hero section with clear call-to-action buttons
* EduQay product overview
* Features and benefits section
* How-it-works section
* Product/dashboard showcase
* Pricing section
* Call-to-action section
* Responsive mobile navigation
* Lucide icons
* Accessible semantic HTML
* SEO-friendly metadata
* Open Graph and social sharing metadata
* Responsive typography using CSS `clamp()`

🛠️ Technologies Used

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Interactive functionality
* **Lucide Icons** — Interface icons
* **Google Fonts** — Typography

🎨 Design System

The landing page uses EduQay's existing visual identity.

Primary Colors

* Blue: `#2563EB`
* Teal: `#14B8A6`

Supporting Colors

* Heading: `#172B4D`
* Secondary text: `#64748B`
* Background: `#F8FAFC`
* White: `#FFFFFF`
* Border: `#E2E8F0`

The design prioritizes clarity, trust, accessibility, and a professional school-management SaaS aesthetic.

📱 Responsive Design

The landing page is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

Responsive sizing is handled using flexible layouts, CSS Grid/Flexbox, media queries, and CSS functions such as `clamp()`.
